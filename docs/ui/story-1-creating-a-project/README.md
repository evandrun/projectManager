User Story
As a manager, I want to create a project so that I can keep projects and details organized.


Acceptance Criteria:
- Must allow the user to fill in the project name, description, list all tasks, assign tasks, and set a deadline.
- Must show an error screen for missing fields and indicate that they are missing.


Team: 
- Designer: Ethan
- Tester: Diego


Screen descriptions
Screen 1: This is the manager's home page where you can view current projects or choose to create a new project.
Screen 2: After clicking Create New Project, the UI prompts you to enter the project name, project description, and list of tasks.
Error screen 2a: If you fail to enter one of the fields, it sends you to this screen, which puts a red box around the field you failed to enter. After you fill in this field, you may hit Continue and go on to the next screen.
Screen 3: After clicking Continue on the previous screen, the UI prompts you to assign the tasks and enter a project deadline.
Screen 4: After you hit Continue on Screen 3, you are shown Screen 4, which is a confirmation screen that lists all of the things you just filled in. If you need to change something, you may hit the back button and return to the previous screens.
Screen 5: After clicking Finish on screen 4 you return to the home screen (Screen 5) that now has your new added project listed under projects.
